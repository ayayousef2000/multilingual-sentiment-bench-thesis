\noindent CNN (англ. Convolutional Neural Network) --- сверточная нейронная сеть

\noindent DAG (англ. Directed Acyclic Graph) --- ориентированный ациклический граф

\noindent DOM (англ. Document Object Model) --- объектная модель документа

\noindent FIFO (англ. First In, First Out) --- принцип последовательной обработки запросов

\noindent FP8 / FP16 / FP32 --- форматы чисел с плавающей точкой (8/16/32 бит)

\noindent GDPR (англ. General Data Protection Regulation) --- общий регламент защиты персональных данных

\noindent GELU (англ. Gaussian Error Linear Unit) --- функция активации на основе гауссовой ошибки

\noindent GPU (англ. Graphics Processing Unit) --- графический процессор

\noindent GRU (англ. Gated Recurrent Unit) --- управляемый рекуррентный блок

\noindent INT4 / INT8 --- целочисленные форматы квантования (4-бит / 8-бит)

\noindent JIT (англ. Just-In-Time) --- динамическая компиляция

\noindent LSTM (англ. Long Short-Term Memory) --- долгая краткосрочная память

\noindent MLM (англ. Masked Language Modeling) --- маскированное языковое моделирование

\noindent NLP (англ. Natural Language Processing) --- обработка естественного языка

\noindent NSP (англ. Next Sentence Prediction) --- предсказание следующего предложения

\noindent ONNX (англ. Open Neural Network Exchange) --- открытый формат обмена нейронными сетями

\noindent RTT (англ. Round-Trip Time) --- время двунаправленной передачи данных по сети

\noindent SIMD (англ. Single Instruction Multiple Data) --- параллельная обработка данных одной инструкцией

\noindent SPA (англ. Single Page Application) --- одностраничное веб-приложение

\noindent SVM (англ. Support Vector Machine) --- метод опорных векторов

\noindent UI (англ. User Interface) --- пользовательский интерфейс

\noindent WASM --- WebAssembly

\noindent WebGPU --- стандарт графического API для браузера
